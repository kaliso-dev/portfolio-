# Les sept sceaux — solutions (divulgâcheur)

Chaque sceau brisé affiche un message ; la commande `sceaux` du terminal montre la progression et des
indices. Les sept réunis ouvrent le trésor (`tresor`) : l'accent **or** (`theme or`) et la marque
`⚜ 7/7` ajoutée aux tickets envoyés ensuite (tu la verras dans le dashboard).

| Sceau | Indice | Solution |
|---|---|---|
| le code des anciens | ↑ ↑ ↓ ↓ … | le code Konami n'importe où : ↑ ↑ ↓ ↓ ← → ← → B A (les couleurs défilent) |
| le salut | la politesse d'abord | taper `salam` (ou سلام) n'importe où sur le site, ou la commande `salam` |
| le chevalier éveillé | réveille le chevalier, sept fois | cliquer 7 fois de suite sur le chevalier de l'accueil (il tournoie) |
| la victoire en duel | croise le fer | gagner le `duel` du terminal (3 touches) |
| le voyageur égaré | perds-toi | ouvrir une page qui n'existe pas (404) |
| le regard du forgeron | regarde sous le capot | ouvrir la console du navigateur et taper `kaliso.sceau()` |
| le polyglotte | parle toutes les langues de la forge | visiter le site dans les trois langues |

Les sceaux sont gardés dans le navigateur du visiteur (localStorage), rien n'est envoyé au serveur.
