# Illustrations du compte rendu de la forge

Dépose ici une image par diapositive du carrousel, nommée exactement ainsi :

| fichier            | diapositive       |
|--------------------|-------------------|
| `plan.webp`        | Le plan           |
| `features.webp`    | Fonctionnalités   |
| `stack.webp`       | Arsenal           |
| `steps.webp`       | Étapes            |
| `range.webp`       | Fourchette        |
| `questions.webp`   | Questions         |

Formats acceptés : `.webp` (conseillé), `.avif`, `.png`, `.jpg`, `.svg`.
Format conseillé : carré, au moins 1200 × 1200 px, fond sombre (l'image remplit la tuile de gauche, coins arrondis).

`build.py` les détecte tout seul : il suffit de les ajouter puis de pousser sur GitHub.
Sans image, la tuile affiche un grand numéro sobre.
